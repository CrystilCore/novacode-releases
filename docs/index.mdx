---
title: "NovaCode"
description: "A block editor that makes Scratch projects, and more."
---

NovaCode is a desktop block editor. It saves real `.sb3` files that open in Scratch and TurboWarp, and it adds
blocks, libraries and tools Scratch doesn't have.
